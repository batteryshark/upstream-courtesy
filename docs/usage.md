# Using the skill

Provide the upstream repository, version, environment, minimal reproduction and observed failure. The agent checks local configuration and the observation method, reads the project's contribution and AI-use policies, and searches for existing reports before drafting.

A useful draft contains version/environment, steps, expected behavior, actual behavior and practical impact. Include only necessary sanitized evidence. Keep credentials, private paths and internal transcripts out of submissions.

The skill stops at a private draft until you approve the destination and exact submission. Follow-ups need their own approval. If the project does not accept AI-assisted contributions, the skill stops rather than disguising them.

See [SKILL.md](../SKILL.md) for the complete workflow. These are agent instructions, not a technical permission boundary.
